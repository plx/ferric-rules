# Format reference bytes

The twelve CLIPS programs and their expected output are retained exactly from
CLIPS 6.30 reference runs in the immutable image identified in provenance.json.
Each program uses normal load, reset and run in a fresh environment. Unit tests
compare the corresponding primitive formatting results to these output bytes;
this directory does not contain output generated by Ferric.

The max-finite-fixed and min-subnormal-fixed expectations instead come from
exact integer arithmetic. Maximum finite f64 is 2^1024 - 2^971; minimum
subnormal f64 is 5^1074 / 10^1074. These are defensive formatter checks, not CLIPS
reference runs: the historical C formatting buffer is too small for such
large fixed-format output.

Width and precision count bytes. Some output therefore contains CR or invalid
UTF-8. Preserve these files byte for byte; do not normalize control characters
or repair decoding. The five noncanonical integer fragments are observations
of the pinned reference platform. The fallback derives them from a normalized
valid prefix and an unchanged suffix; behavior beyond these observations is
an explicit deterministic Ferric policy.
